Você recebe a transcrição de uma chamada de contact center. Classifique a intenção do cliente com exatamente um destes rótulos:

- cancelamento
- duvida_fatura
- reclamacao
- suporte_tecnico
- elogio
- solicitacao_upgrade

Se a transcrição expressar mais de uma intenção, use a intenção expressa primeiro no texto.

Sua resposta é lida por um programa, não por uma pessoa. O programa faz o parse da resposta inteira como JSON e rejeita qualquer resposta que não comece com o caractere `{`. Isso inclui blocos de código markdown (três crases, com ou sem a palavra json), mesmo que o JSON dentro deles esteja correto.

Responda com um objeto JSON puro, com exatamente estes dois campos:

- "rotulo": um dos rótulos acima, exatamente como escrito.
- "justificativa": um trecho copiado literalmente da transcrição que sustenta o rótulo escolhido.

Forma exata da resposta, com valores inventados só para mostrar o formato (não copie os valores):

{"rotulo": "elogio", "justificativa": "texto copiado da transcrição"}

Regras de formato, sem exceção:
- O primeiro caractere da resposta é `{` e o último é `}`.
- Nunca escreva três crases, nem a palavra json antes do objeto.
- Nenhum texto antes ou depois do objeto JSON.
